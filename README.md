IT

Un’animazione in Python realizzata con Manim che rappresenta l’Orbita Quantistica. Il progetto include un video già renderizzato e mostra il comportamento dinamico delle particelle, la distribuzione di densità probabilistica e transizioni di camera fluide. È stato sviluppato sia come dimostrazione scientifica sia come esercizio personale di animazione complessa e rendering avanzato.

EN

A Python animation created with Manim that visually represents a Quantum Orbital. The project includes a fully rendered video and features dynamic particle motion, probabilistic density visualization, and smooth camera transitions. It was built both as a scientific demonstration and as an experiment in high‑complexity animation rendering.
